# Tbilisi, in English

Одностраничный сайт авторской поездки Дианы в Тбилиси, 5–9 ноября 2026.

Откройте `index.html` в браузере. Сайт не требует сборки или установки зависимостей.

## Файлы

- `index.html` — структура и контент
- `styles.css` — визуальная система и адаптивность
- `script.js` — маршрут, привязанный к прокрутке, и навигационный индикатор
- `assets/` — изображения сайта
